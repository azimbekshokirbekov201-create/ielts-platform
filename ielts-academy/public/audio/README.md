# Original listening audio

`riverside.wav` narrates the original `listeningScript` in `src/data/content.ts`.
It was synthesized offline using FFmpeg's Flite filter and the bundled `slt` voice, at 22,050 Hz mono PCM.
Duration: 31.04 seconds. No external IELTS recording was used.

Flite is provided by Carnegie Mellon under its permissive license; see https://github.com/festvox/flite/blob/master/COPYING for the synthesizer's license. The resulting original educational script is part of this demo source project.
